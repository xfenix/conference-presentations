Алиасы локальных моделей

  • base — универсальная, есть режим рассуждений
  • base-vlm — текст + изображение
  • large — высокая точность, сложные задачи
  • small — быстрая, для простых задач
  • embedding/embedding-large — текст в векторы, для RAG
  • reranker — для реранкинга
  • coding — генерация кода
