Петля

Агентный цикл — это while

упрощённо, по описанию Runner в OpenAI Agents SDK

def run(task, tools, max_turns=10):
    messages = [task]
    for _ in range(max_turns):
        reply = llm(messages, tools)
        messages.append(reply)
        if not reply.tool_calls:
            return reply.text
        for call in reply.tool_calls:
            messages.append(tools[call.name](**call.args))
    raise MaxTurnsExceeded

Скиллы

Скилл изнутри

открытый стандарт agentskills.io
  • Папка с файлом SKILL.md: шапка name и description, ниже инструкция
  • На старте агент видит только описание — около 100 токенов на скилл
  • Остальное агент читает, только когда скилл нужен. Стандарт советует до 500 строк
  • Папки scripts/, references/, assets/ — тоже по запросу
  • Один и тот же скилл работает в разных агентах

Пример скилла

от description зависит, позовёт агент скилл или нет

---
name: release-notes
description: Собирает release notes из коммитов с последнего тега.
  Звать, когда просят changelog или «что нового в релизе».
---

1. Найди последний тег: `git describe --tags --abbrev=0`
2. Возьми коммиты после него: `git log <тег>..HEAD --oneline`
3. Разложи по группам: фичи, фиксы, прочее
4. Технические коммиты (merge, bump, ci) выкинь

Хук

надёжнее просьбы в промпте: его выполняет харнесс
  • Скрипт на событие: перед вызовом инструмента, после правки, на старте
  • В справке Claude Code 33 события
  • Код выхода 2 — действие запрещено, текст ошибки получает модель

Хук на Python

после каждой правки: код выхода 2 — агент видит ошибки ruff

#!/usr/bin/env -S uv run --script
# /// script
# requires-python = ">=3.12"
# ///
import json, subprocess, sys

path = json.load(sys.stdin)["tool_input"].get("file_path", "")
if path.endswith(".py"):
    check = subprocess.run(
        ["uvx", "ruff", "check", path], capture_output=True, text=True
    )
    if check.returncode:
        print(check.stdout, file=sys.stderr)
        sys.exit(2)

Бесплатно и встроено

начинать отсюда
  • /clear между задачами. /compact — сам по себе большой запрос
  • CLAUDE.md до 200 строк. Редкие правила — в .claude/rules/ и скиллы
  • Шумную задачу — агенту-помощнику: в разговор вернётся только итог
  • Повтор дешевле, пока жив кэш: час на подписке, 5 минут при оплате по токенам
  • /context и /usage — что занимает окно и сколько стоит

Сжать то, что читает агент

  • rtk, 82k ★: хук подменяет git status на rtk git status и режет вывод
  • Авторы обещают до −90% вывода Bash. Счёт падает меньше — пишут они же
  • context-mode, 24k ★: длинный вывод остаётся снаружи, агенту — только итог. 315 КБ → 5,4 КБ
