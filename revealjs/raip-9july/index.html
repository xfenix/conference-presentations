Выбор технологий

Векторная база данных

  • Основной кандидат: Milvus (через Андрея Суханя)
  • Альтернатива для отдельных случаев: pgvector

LLM Gateway

  • Требуется унифицированный интерфейс для работы с разными LLM
  • Обоснование: централизованное управление моделями, квотами, мониторинг

Отношения с Андреем Суханем

  • Потенциальное сотрудничество по Milvus
  • Необходимо проработать условия взаимодействия

Интеграция LLM Playground с платформой

  • План поэтапного объединения функционала
  • Унификация API и интерфейсов управления

Выбор провайдера LLM

  • Основной кандидат: Just.ai
  • Текущий статус: пилотирование
  • Преимущества: используется в топ-5 банках, гибкость

Альтернативы Just.ai

  • AIR (air.fail)
  • Проблемы: малая команда (1.5 человека), низкая надежность
  • Технические проблемы, высокая наценка на токены

План на ближайшие месяцы

  • Проведение тендера (3-4 месяца)
  • Окончательный выбор провайдера LLM
  • Интеграция выбранных решений
